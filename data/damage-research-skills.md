# 와일즈 공통 피해 스킬 조사

조사일: 2026-09-16. 범위: **몬스터헌터 와일즈 기본 게임 TU4~1.041**.

자동 계산용 자료는 [damage-research-skills.json](./damage-research-skills.json)에 있다. 게임 코드 수정은 포함하지 않는다. 먼저 로컬 `database.json`의 한국어 ranks를 추출하고, 원작성자 가이드와 계산기 구현에서 수치를 교차 확인했다. 로컬 DB의 출처 URL을 기록한 것은 이번에 원격 API를 새로 조회했다는 뜻이 아니다.

## 먼저 적용할 수 있는 공식

- **힘의 부적: 기초 공격력 +6.** 기준값에 한 번만 넣는다. [와일즈 태도 가이드 FAQ](https://wiggler.pet/wilds/endgame/longsword)
- 기초공격 배율은 무기 자체 기초공격에 곱하고, 고정 보너스는 그 뒤 더한다. 따라서 힘의 부적이나 도전자의 고정 공격력까지 공격·공격적인 방어의 배율로 곱하면 안 된다. [와일즈 슬래시액스 가이드의 계산식](https://wiggler.pet/wilds/guide/switch_axe)

```text
R = 무기 기초공격 × Π(1 + 활성 rawPercent) + 6 + Σ(활성 rawFlat)
a = clamp(최종 회심률, -100, 100) / 100
Craw = a ≥ 0 ? 1 + a × (양회심 배율 - 1) : 1 + 0.25 × a
EFR = R × Craw
```

기본 양회심은 1.25배, 음회심은 0.75배다. 슈퍼회심은 양회심 배율을 바꾸며 음회심에는 영향이 없다. 회심이 불가능한 공격 성분에는 `Craw=1`을 쓴다. 공용 가이드에서는 **Wilds라고 명시된 회심 설명만** 사용했고, Rise 회심격속성 표는 사용하지 않았다. [회심 설명](https://wiggler.pet/other/guides/intermediate_damage_calculation)

위 EFR은 모션·육질·예리도·공격 속도를 정하지 않은 물리 기대 공격력이다. 실제 총 피해나 DPS와 같지 않다. 일반 타격 피해는 물리/속성 성분을 따로 계산해 합하며, 폭발·병·음파·특수탄은 성분별 규칙이 필요하다. 메뉴 수치는 버림되지만 내부 계산에는 소수가 남으므로 중간값을 메뉴처럼 버리지 않는다. [와일즈 전용 공식 및 반올림 설명](https://wiggler.pet/wilds/guide/switch_axe)

## 공통 스킬 수치

아래는 **해당 조건이 발동한 상태**의 수치다. 레벨 순서대로 나열했다. 로컬 DB ranks와 [와일즈 계산기 원작성자의 스킬 구현](https://github.com/chanleyou/mhwilds-calculator/blob/bbcb44f783fe20fcaf694654bd9d55fea2e430ff/src/data/skills.ts)을 대조했다.

| 스킬 | 레벨별 효과 |
|---|---|
| 공격 | +3 / +5 / +7 / ×1.02+8 / ×1.04+9 |
| 간파 | 회심 +4 / 8 / 12 / 16 / 20%p |
| 약점 특효 | 약점 +5 / 10 / 15 / 20 / 30%p, 상처 추가 +3 / 5 / 10 / 15 / 20%p |
| 도전자 | 기초공격 +4 / 8 / 12 / 16 / 20, 회심 +3 / 5 / 7 / 10 / 15%p |
| 혼신 | 회심 +10 / 20 / 30%p |
| 공격적인 방어 | 기초공격 배율 ×1.05 / 1.10 / 1.15 |
| 역습 | 기초공격 +10 / 15 / 25 |
| 교격 | 기초공격 +10 / 15 / 20 / 25 / 30 |
| 앙심 | 기초공격 +5 / 10 / 15 / 20 / 25 |
| 완전 충전 | 기초공격 +3 / 6 / 10 / 15 / 20 |
| 재난대처능력 | 피해배율 ×1 / 1.05 / 1.05 / 1.10 / 1.30 |
| 슈퍼회심 | 양회심 배율 1.28 / 1.31 / 1.34 / 1.37 / 1.40 |
| 5속성 공격 강화 | 표시속성 +40 / ×1.10+50 / ×1.20+60 |

속성 증가량은 DB의 **표시속성 단위**다. 일반 무기는 실제 속성 피해 계산 시 10으로 나눈다. 속성탄에 무기 표시속성 0을 그대로 대입하면 안 된다. 보우건은 탄의 별도 속성식을 사용해야 한다.

## 무기별 예외

연격은 5회 적중 후의 **최종 보너스**를 기록했다. 초기 효과에 표의 수치를 다시 더하지 않는다. 한손검 초기 단계는 +5 raw/+50 표시속성 직접 실측이 있지만, 다른 무기 초기 단계와 정확한 유지시간은 이번 조사에서 확정하지 않았다. [한손검 실측](https://www.reddit.com/r/MHWilds/comments/1j175di/burst_skill_buff_numbers/)

| 연격 무기군 | 기초공격 Lv1~5 | 표시속성 Lv1~5 |
|---|---|---|
| 대검·수렵피리 | 10/12/14/16/18 | 80/100/120/160/200 |
| 쌍검 | 8/10/12/15/18 | 40/60/80/100/120 |
| 활 | 6/7/8/9/10 | 40/60/80/100/120 |
| 라보·헤보 | 6/7/8/9/10 | 미확인 |
| 나머지 근접 무기 | 8/10/12/15/18 | 60/80/100/120/140 |

이 무기군 구분은 [원작성자 스킬 구현](https://github.com/chanleyou/mhwilds-calculator/blob/bbcb44f783fe20fcaf694654bd9d55fea2e430ff/src/data/skills.ts)을 사용했다. 차액의 수치는 [TU4.5 차지액스 가이드](https://docs.google.com/document/d/1I9XKBQZLpG0159yPOs2zvPS7wwrzaEPtiMkBfzGzibQ/edit)에서 추가 확인했다.

회심격【속성】은 일반군 1.05/1.10/1.15배, 대검·해머·수렵피리는 원작성자 구현에서 1.07/1.14/1.21배다. **헤보는 해당 구현의 21%와 현재 MHGH 헤보 가이드의 15%가 충돌하여 자동 적용을 보류했다.** [헤보 가이드](https://docs.google.com/document/d/17atnsKzYrQlEy_70Z2zzlEBJrN3OtiTYurKCHzMLIn8/edit)

전화위복은 JSON에 무기군별 속성 배율을 분리했다. 구작의 고정 공격력 보너스를 넣지 않는다. 상태 축적 배율도 직접 피해 배율로 간주하지 않는다.

## 비교 기준과 가정

사용자 기준은 `선택무기 고유 수치 + 힘의 부적`을 1.00으로 둔다.

- 전체 기여: `D(전체 스킬) / D(기준)`
- 개별 스킬의 한계 기여: `D(전체 스킬) / D(해당 스킬만 제거)`

개별 값은 상호작용 때문에 서로 곱해서 전체 값이 되지 않는다. 목표 스킬 집합과 실제 결과의 발동 집합은 같은 계산기에 넣되, 동일한 조건·타격 시나리오를 사용해야 한다.

발동률은 게임 상수가 아니다. 도전자처럼 raw와 회심이 함께 바뀌는 조건은 상태별 피해를 계산한 뒤 확률 평균한다. 체력은 단일 범주로 두어 완전 충전과 재난을 동시에 켜지 않는다. 한손검 가이드의 도전자 70%·공격적인 방어 40%는 **특정 모델의 가정 예시**로만 기록했다. [가정의 출처](https://wiggler.pet/wilds/endgame/sword_and_shield)

## 미확인 항목

- TU4 속성상한 `max(기초속성×2.3, 기초속성+400)`은 쌍검 실측 보고와 일치하지만 원본 파라미터를 검증하지 못해 후보값으로만 남겼다. **구판 1.9배/+350 사용 금지.** [TU4 실측 보고](https://www.reddit.com/r/MHWilds/comments/1q1zzbp/is_this_the_max_elemental_cap_now/)
- 물리 공격력 상한, SA 병의 추가 속성상한 보정, 보우건 연격의 속성 성분, 타격별 마지막 반올림은 미확인.
- 집중·포탄 장전·체술 등은 공격 주기/동작에 영향을 줄 수 있어 단순 직접 피해 증가 0과 실제 DPS 중립을 혼동하지 않는다.
- 발동 피해·상태이상·미검증 시리즈 스킬은 `unknown`으로 남긴다. 미산정 값을 1.00으로 표시하지 않는다.

검증: JSON 파싱, 20개 스킬의 DB 이름·최대 레벨, 모든 출처 참조, 연격 무기군 14종 분할을 확인했다.

# 와일즈 건랜스 피해 구성 조사

기준: **와일즈 기본 게임 TU4(1.040) 데이터마이닝 + 1.041 공식 변경 내역 확인**, 2026-09-16 조사. 수치는 [구조화 JSON](damage-research-gunlance.json)에 저장했다. 1.041 공지에서 건랜스 피해 변경은 확인되지 않았으나 바이너리 전체의 동등성을 검증한 것은 아니다.

## 계산에서 반드시 나눌 공격

- **참격**: 참격 육질·예리도·회심·무기 속성 적용.
- **용항포 연속 틱**: 참격 육질·회심·무기 속성 적용. 예리도 피해 배율은 미적용. 포술은 raw에 적용되고 속성에는 미적용.
- **용항포 마지막 폭발 / 포격 / 용격포**: raw는 참격 육질과 회심을 무시한다. 무기의 속성이 아니라 별도 고정 화염 성분을 갖는다.

용항 틱의 회심·속성 적용은 **1.011 공식 변경**이다. 출시 시점의 “용항은 회심·무기 속성을 받지 않는다”는 분석을 현행 공식에 혼용하면 안 된다. 현재 [dtlnor 원본](https://github.com/dtlnor/mhws-rcol-record/blob/238121acdddc5668bef186b81fbad6927a3cef34/Player/Wp07.csv)의 틱 항목은 `IsNoCritical=False`, `UseStatusAttrPower=True`, `IsNoUseKireaji=True`로 구분된다. [CAPCOM 1.011 공지](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/1800991756290109)

아래 순서는 **일반 / 방사 / 확산**이다. MV는 true raw의 백분율이며 고정 피해 숫자가 아니다.

|---|---|---|
| 기본 포격 MV | 9 / 12 / 21 | 10 / 13 / 23 |

| 용항 1틱 MV | 7 / 8 / 7 | 8 / 9 / 8 |
| 용항 마지막 폭발 MV | 28 / 42 / 27 | 31 / 49 / 30 |
| 용항 마지막 폭발 화염 | 23 / 23 / 23 | 25 / 25 / 25 |

포격 raw 배율은 일반 풀버스트 **1.4 / 1.4 / 1.35**, 용항 풀버스트 **1.25 / 1.1 / 1.05**, 모아포격 **1.8**이다. 고정 화염에 같은 배율을 곱하지 않는다. 용격포는 5타. 용항은 일반·첫 용항 풀버스트 9틱, 연속 용항 풀버스트 15틱이며 틱마다 무기 속성 ×0.5다. 연속 용항 마지막 폭발 raw는 ×1.1이다. ## 대표 공격 묶음과 파생 비중

**사용 비율을 실측한 값이 아닌 비교 예시**다. 가정: true raw 300, 가산 raw 0, true 속성 30, 회심 0%, 흰 예리도, 참격 육질 0.60·무기 속성 육질 0.20·불 육질 0.15, 포술 3·포탄 장전 2·포격 위력 4. 각 공격이 모두 같은 부위에 명중한다고 두었다.

| 공격 묶음 | 회심 가능한 물리 | 비회심 포격·폭발 | 무기 속성 |
|---|---:|---:|---:|
| 일반: 내려치기 + 7발 풀버스트 | 26.8% | 70.5% | 2.7% |
| 일반: 찌르기 2회·후려치기 → 용항 풀버스트 2단 | 45.4% | 47.2% | 7.4% |
| 위 일반형 묶음을 각각 1회 합산 | 41.4% | 52.2% | 6.4% |
| 방사: 찌르기 2회·후려치기·일반 용항포 | 66.6% | 21.8% | 11.6% |
| 확산: 3발 모아포격 2회·용격포 1회 | 0% | 100% | 0% |

이것은 타입별 고정 계수가 아니다. 예를 들어 참격 육질만 0.45→0.80으로 바꾸면 일반 혼합 묶음의 회심 가능 물리 비중은 **34.7%→48.5%**, 방사는 **59.9%→72.6%**로 바뀐다. 확산의 0%는 참격을 넣지 않은 지정 공격 묶음의 결과이며, 확산 건랜스 전체가 무기 속성을 쓰지 못한다는 뜻이 아니다.

일반형 두 묶음의 합은 **독립된 공격 묶음의 합산**이다. 풀버스트로 탄창을 비운 다음 첫 용항 풀버스트에서도 가득 찬 탄을 다시 발사하는 불가능한 연계를 만들지 않았다. JSON의 각 `representativeCycles`에 실제 공격 구성과 탄창 횟수, Lv3·4/포탄 장전별 합계를 넣었다. 시뮬레이터는 고정 비중 대신 이 합계에 현재 장비 수치를 넣어 다시 계산하는 편이 낫다.

## 스킬과 시간 처리

- **포술**: 기본 raw 계열 ×1.05/1.10/1.15와 고정 true 화염 +3/6/9. 모든 가산 공격력까지 무조건 1.15배로 계산하지 않는다. 용항 틱의 무기 속성에 포술을 곱하지 않는다.
- **포탄 장전**: Lv2는 탄창 +1, 기본 6/3/2발 → 7/4/3발. 한 발의 위력 증가가 아니다. 장전 속도 향상도 있으나 전체 재장전 시간은 이번 조사에서 미산정.
- **집중**: 모아포격 충전 시간 ×0.95/0.90/0.85와 게이지 상승 증가. 용격포 발사를 빠르게 하는 것은 명시적으로 포술 효과이며, 집중이 용격포 자체의 준비 시간도 줄인다는 현행 검증은 확보하지 못했다.

전체 반복 시간 중 **집중에 반응하는 모아포격 충전 시간**의 비중을 사용자가 `f`로 가정하면 `1 / (1 - f × 0.15)`는 집중 3의 회전율 근사로 쓸 수 있다. `f=0.25`는 실측 근거 없는 입력 가정이며 용격포·재장전·후딜·이동 시간을 포함하지 않는다. 게이지 증가로 용격포 횟수가 늘어나는 효과도 이 식에는 없다. [동봉 한글 스킬 데이터](database.json), [원저자 집중 비교](https://www.reddit.com/r/Gunlance/comments/1l7y7g6/)

전체 콤보 시간은 신뢰할 수 있는 TU4 실측을 확보하지 못해 JSON의 `durationSeconds`를 **null**로 두었다. 원본의 모아포격 시간 파라미터나 `GuardQuickReloadTime=0.5`를 전체 애니메이션 시간으로 간주하면 안 된다. [건랜스 원본 파라미터](https://github.com/dtlnor/mhws-rcol-record/blob/238121acdddc5668bef186b81fbad6927a3cef34/Player/GlobalActionParam/individual_wp07.csv)

## 아직 확정하지 않은 항목

용격포 2~5타 불 육질 상한, 연속 용항 폭발의 고정 화염에도 1.1배가 적용되는지, 회심격【속성】의 건랜스별 계수, 상처·상태이상·추가 피해 스킬의 실제 가동률은 미산정이다. 예시의 고정 화염은 같은 불 육질을 일괄 적용한 근사다. 공격 묶음의 상대 기대피해를 서로 다른 운용의 **DPS나 수렵 전체 실측 피해**로 표시하지 않는다.

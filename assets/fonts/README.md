400·500·600·700·800 굵기를 WOFF2로 압축했습니다. 글리프를 삭제하거나 형태를 변경하지 않았습니다.
`scripts/build-fonts.py`가 로컬 파일을 이용해 `dist/fonts.css`를 재생성합니다.
웹앱은 외부 폰트 서버에 접속하지 않으며, 단일 HTML에서도 동일한 글꼴을 사용합니다.

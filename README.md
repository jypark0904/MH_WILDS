# MH: WILDS 장비 시뮬레이터

**`와일즈-장비시뮬레이터.html`을 더블클릭해서 실행하세요.**

별도 설치·서버·인터넷 연결 없이 실행됩니다. 최신 Chrome/Edge 권장. `dist/index.html`도 같은 앱이며 `dist` 폴더의 나머지 파일을 함께 두어야 합니다.

Google 로그인 웹 배포본: [https://mh-wilds.web.app](https://mh-wilds.web.app)

## 사용 순서

1. **내 장비**에서 아티어·거극 아티어 무기와 랜덤 호석을 등록합니다. 제작 무기·호석은 **장비 도감 → 내 장비에 추가**로 가져올 수 있습니다.
2. 이름에 실제 무기명이나 무기 종류를 입력하면 종류가 자동 선택됩니다. 거극 아티어는 **격화·속성·복원 보너스 5개의 종류/레벨**을 선택하면 수치가 계산되고 무기용 슬롯 **3·3·3**이 고정됩니다. 일반 무기·아티어와 호석은 실제 스킬·슬롯을 입력합니다.
3. **내 장비 → 방어구 해금**에서 수렵한 세트를 체크합니다. 초기값은 **183세트 전체 체크·레어도 높은순**입니다. 높은/낮은 레어도순, 가나다순/역순 정렬과 세트 이름 검색, 상위·하위 필터, 표시된 세트 일괄 체크/해제를 지원합니다. 체크를 해제하면 해당 세트의 모든 부위가 검색에서 제외됩니다.
4. **조합 검색**에서 `도전자5 약점특효3`처럼 스킬 이름과 최소 레벨을 입력합니다. 자동완성으로 고르거나 여러 스킬을 한 번에 추가할 수 있습니다. 부위 고정, 희귀도, 상·하위, 최소 방어력, 호석 사용 조건을 조정할 수 있습니다.
5. 방어구는 항상 **한계돌파·최대 강화 완료**로 계산합니다. 상위는 돌파 후 슬롯·최대 방어력, 하위는 기본 최대 강화 수치를 사용합니다. 제외된 세트의 고정부위는 자동으로 해제합니다.
6. 장식주 보유량을 제한하려면 도감에서 수량을 입력하고 **내가 등록한 수량만**을 선택합니다. 기본값은 모든 장식주 수량 무제한입니다.
7. 자주 쓰는 조건은 **검색 프리셋**에 이름을 붙여 저장합니다. 불러오기·덮어쓰기·삭제를 지원하며, 검색 결과를 저장하는 기능과 별개입니다.
8. 결과 카드를 클릭하면 **바로 아래에 상세가 펼쳐집니다.** 무기·방어구 5부위·호석의 이름과 고유 스킬, 각 슬롯에 넣을 장식주, 빈 슬롯을 확인하세요. 같은 카드를 다시 누르면 접힙니다. 조합 저장 및 텍스트 복사를 지원합니다.

**검색은 8초 또는 20개 결과마다 멈춥니다.** `이어서 더 찾기`는 기존 탐색 위치에서 재개합니다. 발견한 결과 안에서 성장 여유순(기본), 목표 스킬 초과 레벨순, 방어력순, 빈 슬롯 개수순으로 정렬합니다. 전체 탐색이 끝나지 않았으면 전체 최적해 또는 불가능 판정을 주장하지 않습니다.

**보유 호석 전체 비교**는 호석 없음과 각 보유 호석의 탐색을 순환합니다. 첫 호석의 조합만으로 초기 결과가 채워지거나 어려운 호석 조건 때문에 다음 호석의 탐색이 계속 밀리는 일을 줄였습니다. 탐색을 이어갈 때도 각 호석의 진행 위치를 유지합니다. 무기·호석이 이미 제공하는 스킬과 시리즈 기여를 차감한 뒤, 호석별로 남은 요구량에 맞춰 방어구 후보의 탐색 우선순위를 정합니다.

### 추가 제안

- 기본 **성장 여유순**은 빈 슬롯의 레벨 합 → 빈 3레벨 슬롯 개수 → 목표 스킬 초과 레벨 → 방어력 순입니다. 카드에 무기용·방어구용 빈 슬롯을 따로 표시합니다. 이 순서는 추가 장식주를 넣을 여유를 비교하며 화력 순위가 아닙니다.
- **목표 스킬 더 올리기**에서 현재 목표의 다음 레벨을 제안합니다. 이미 발견한 조합이 충족하면 확인된 조합 수와 발견 최고 레벨을 표시하고, 아직 확인되지 않았으면 **가능 여부 검색**으로 표시합니다.
- **무기에 맞는 추가 스킬**을 펼치면 현재 무기 종류·속성에서 효과가 확인된 추가 스킬을 최대 6개 제안합니다. 일치하는 속성 강화를 먼저 표시하며, 다른 무기 전용 효과·불일치 속성·적용 조건이 미확인인 효과는 자동 제안에서 제외합니다. 직접 입력한 목표는 유지합니다.
- 제안을 누르면 나머지 목표와 장비·해금·수량 조건을 유지하면서 해당 스킬을 추가하거나 높여 다시 검색합니다. 제안은 개별 적용하며, 각각의 가능성을 동시에 성립한다고 가정하지 않습니다.
- **이전 조건·결과로 돌아가기**로 바로 전 목표와 발견한 결과를 복원할 수 있습니다. 직접 조건을 수정하면 되돌리기 기록은 해제됩니다. 복원한 결과에서 다시 탐색하려면 조합 검색을 누릅니다.
- 확인된 최고 레벨은 발견한 결과 범위의 값이며, 전체 장비 조합의 이론적 최댓값을 의미하지 않습니다.

### 스킬 메시지와 자동완성

- `도전자 5, 약점 특효 3`, `도전자5 약점특효3`, `도전자 Lv.5`처럼 입력할 수 있습니다. 이름만 적으면 Lv 1을 추가합니다.
- 입력 중 표시되는 후보를 클릭하거나 **↑/↓**로 고른 뒤 **Enter**를 누릅니다. 완성된 메시지는 **추가** 버튼이나 Enter로 한 번에 반영하며 **Shift+Enter**는 줄바꿈입니다.
- `약특`, `슈회` 같은 등록된 별칭과 띄어쓰기 없는 이름도 인식합니다. 기존 목표 스킬을 다시 입력하면 해당 레벨을 바꿉니다.
- 알 수 없는 이름이나 범위를 벗어난 레벨이 있으면 이유를 표시하고 메시지 전체를 반영하지 않습니다. 추가한 뒤에는 기존 레벨 선택과 제거 버튼으로 수정할 수 있습니다.
- 로컬 입력 기능이므로 메시지가 외부 서버나 AI 서비스로 전송되지 않습니다.

### 검색 프리셋

- 이름을 입력하고 **현재 검색 조건 저장**을 누릅니다. 최대 **30개**까지 저장합니다.
- 목표 스킬, 선택 무기, 호석 비교 방식·고정 호석, 상·하위, 최대 레어도, 최소 방어력, 장식주 수량 제한 방식, 방어구 고정을 저장합니다.
- 저장된 항목을 선택해 **불러오기**, **덮어쓰기**, **삭제**할 수 있습니다. 같은 이름으로 새로 저장하려 하면 기존 항목의 덮어쓰기를 안내합니다.
- 프리셋을 불러와도 **현재 보유 장비·방어구 해금·장식주 수량은 유지됩니다.** 예전 파밍 현황으로 돌아가지 않습니다.
- 저장했던 무기가 삭제되면 무기 미지정, 고정 호석이 삭제되면 보유 호석 전체 비교로 바꾸고 안내합니다. 없거나 미해금 상태이거나 불러온 등급·레어도 조건에 맞지 않는 방어구 고정도 해제합니다.

### 결과의 장식주 배치 읽기

카드 아래 상세에는 **무기 → 머리 → 몸통 → 팔 → 허리 → 다리 → 호석** 순서로 7개 장비가 표시됩니다. 각 슬롯의 **번호·무기용/방어구용·레벨**과 넣을 장식주 이름, 장식주가 더하는 스킬을 보여줍니다. 장착하지 않는 칸은 **비어 있음**, 슬롯 자체가 없는 장비는 **슬롯 없음**으로 표시합니다. 호석의 고유 스킬과 혼합 슬롯도 같은 방식으로 확인할 수 있습니다.

목표 스킬을 채우는 정도와 실제 사용하는 슬롯 크기가 같으면 **무기 속성과 일치하는 추가 효과 → 무기에서 유효한 다른 추가 효과 → 낮은 장식주 레벨** 순으로 고릅니다. 예를 들어 용속성 건랜스에 가드 성능1이 부족하고 무기용3슬롯을 사용한다면 **파룡-철벽주【3】**로 가드 성능1과 용속성 공격 강화3을 함께 확보할 수 있습니다. 상세에는 추가 효과를 고른 이유를 표시합니다.

이미 최대 레벨인 효과는 추가 이득으로 계산하지 않으며, 방어구·호석 기본 스킬과 앞서 배치한 장식주도 합산합니다. 보유한 장식주만 사용하는 조건과 사용자가 직접 요구한 스킬은 계속 지킵니다. 무기가 미지정이거나 추가 효과를 확인하지 못한 동점에서는 낮은 장식주 레벨 등을 기준으로 고릅니다. 작은 장식주를 넣어도 원래 슬롯 한 칸 전체를 사용합니다. 분류 근거와 한계는 [무기별 유효 스킬](data/무기별-유효스킬.md)을 참고하세요.

### 거극 아티어 입력

- `내 거극 아티어 건랜스`, `마비용 [전조의 프로페네시스]`처럼 별명을 붙여도 종류·분류를 인식합니다. 종류와 분류를 직접 바꿀 수도 있습니다.
- 이름의 속성도 순서와 관계없이 인식합니다. **용, 화/불, 수/물, 번개/뇌, 마비, 독, 수면, 폭파, 얼음/빙**과 `용속`·`빙속성` 같은 표기를 지원합니다. 예: `용속 거극아티어 건랜스`, `건랜스 거극아티어 [빙]`. 서로 다른 속성을 여러 개 적으면 현재 선택을 유지하고 안내합니다. 수동 선택과 이미 저장한 옵션도 유지합니다.
- 건랜스는 **공격 격화 → 일반형 / 회심 격화 → 방사형 / 속성 격화 → 확산형**으로 연동됩니다. 14종 무기를 지원합니다.
- 생산 보너스는 처음에 **공격력 3개·동일 속성 파츠 3개**로 설정됩니다. 다르게 만들었다면 접힌 **생산 보너스** 영역을 열어 수정하세요.
- 복원 보너스 5개는 종류와 I·II·III·EX 중 실제 가능한 레벨을 선택합니다. 같은 종류·레벨의 중복 제한과 거극 전환 때 계승한 I 옵션을 검사합니다.
- 표시 공격력·회심률·속성·흰 예리도 또는 장전 보너스를 즉시 계산합니다. 선택한 옵션은 저장·수정·JSON 백업으로 유지됩니다.
- 시리즈 21종과 그룹 14종 중 각각 1개를 선택하며, 조합 검색에서 각각 1부위로 계산합니다.
- 장식주 **슬롯**이 고정되며, 장식주는 목표 스킬과 보유량에 맞춰 검색기가 배치합니다.

계산 기준과 출처, 대조한 실제 세팅은 [거극 아티어 계산 기준](data/거극아티어-계산기준.md)에 정리했습니다.

### 호석 레어도 확인

호석 전용 이름·메모 입력란에서 감정/제작 호석을 선택하고 레어도를 입력합니다. 감정 호석은 레어도 5~8의 실제 스킬·슬롯 추첨 패턴 100개, 제작 호석은 도감 183단계와 대조합니다.

내용이 맞지 않으면 **빨간 느낌표와 이유**, 가능한 경우 맞는 레어도를 표시합니다. 경고가 있어도 입력을 저장할 수 있으며 저장 목록에도 느낌표가 남습니다. 레어도·종류·스킬·슬롯은 수정과 JSON 백업에 유지됩니다. 상세 근거는 [호석 레어도 검사 기준](data/호석-레어도-검사.md)을 참고하세요.

### 방어구 선택 방식

이전 개인 방어구 입력 화면을 세트별 수렵 완료 체크 목록으로 변경했습니다. 검색은 체크한 도감 방어구만 사용합니다. 이전 백업의 개인 방어구 레코드는 보존하지만 새로운 검색에는 사용하지 않습니다. 기존에 일부 부위만 제외한 세트는 전체 미체크 상태로 이전합니다.

- 향후 신규 장비를 자동 갱신하지 않습니다. 원본 스냅샷 시점 이후 콘텐츠 변경이 있으면 수집·보충 데이터 갱신이 필요합니다.

## 저장과 백업

Firebase Hosting 배포본의 개인 장비, 해금 여부, 장식주 수량, 검색 조건, 프리셋, 저장 조합은 로그인한 UID별 `users/{uid}` Firestore 문서에 동기화합니다. 현재 브라우저의 `localStorage`는 DTCG BUILDER와 같이 최초 이관·로컬 복사본으로 유지하며, 서버 문서가 있으면 서버본을 기준으로 복원합니다. **내 장비 → JSON 백업/백업 불러오기**는 수동 복사본과 다른 origin의 기존 데이터 이관에 사용합니다.

## 웹 배포와 로그인

Firebase Hosting 배포본은 Google 로그인이 필요합니다. DTCG BUILDER와 동일한 세 계정만 허용하며 지정된 한 계정은 마스터로 표시됩니다. 이메일은 소문자로 정규화하고 Google에서 이메일 확인이 끝난 계정만 허용합니다. 공개 저장소에는 계정 주소 대신 SHA-256 지문만 포함합니다.

배포본은 DTCG BUILDER와 같은 흐름으로 약 450ms 뒤 저장하고 실시간 스냅샷을 구독합니다. 서버 문서가 없을 때만 기존 로컬 상태를 최초 업로드하고, 문서가 있으면 서버 상태를 적용합니다. 로컬 파일과 `localhost` 개발 서버에서는 기존처럼 로그인 없이 로컬 모드로 실행됩니다.

Firebase 프로젝트는 `mh-wilds`, 호스팅 배포 대상은 `dist/`이며 Firestore 규칙·인덱스도 함께 배포합니다.

```powershell
npm install
npm run deploy:firebase
```


## 개발

### 무기별 추천 스킬

무기를 선택하면 목표 스킬 입력 전에 **무기별 스킬 추천**이 표시됩니다. 와일즈 기본 게임 TU4~1.041 환경을 조사한 14종·28개 운용 유형을 동봉했습니다. 추천 레벨은 세팅을 시작하기 위한 기준이며, 조건부 효과는 추천 이유에서 확인할 수 있습니다.

- 건랜스의 포격형, 차지액스·슬래시액스의 병, 활의 확인된 속성을 읽어 유형을 고릅니다. 정보가 없으면 직접 선택합니다.
- 확산형 건랜스: 집중3·포탄 장전2·포술3·가드 성능3. 일반형·방사형은 집중 대신 연격1을 핵심 추천합니다.
- 보우건은 주력 탄과 속성탄 속성을 직접 선택합니다. DB에 지원 탄이 기록된 무기는 그 범위 안에서 추천합니다.
- 개별 스킬이나 핵심 추천 전체를 눌러 목표에 추가합니다. 기존 목표와 더 높은 레벨은 유지하고, 유형 선택만으로 목표를 바꾸지 않습니다.
- 선택 추천, 추천 이유, 원작성자 출처와 조사일을 펼쳐 확인할 수 있습니다. 추천 데이터는 HTML에 포함되어 오프라인에서도 작동합니다.
- 원자료: `data/meta-research-*.json`. 빌드 시 게임·14종 범위·한국어 스킬명·최대 레벨·출처를 검사하고 `data/weapon-meta.json` 및 `dist/weapon-meta-data.js`를 생성합니다.

런타임 의존 패키지가 없습니다. 빌드·테스트에는 Node.js 22 이상을 사용합니다.

```powershell
npm start
npm test
npm run build
```

`npm start`는 `http://127.0.0.1:4173`에서 개발용 파일을 제공합니다. `npm run build`는 DB를 정규화하고 단일 HTML을 다시 생성합니다.

DB 갱신은 `npm run data:fetch` 후 보충 자료를 재검증하고 빌드합니다. 수집 도구 외에는 네트워크가 필요하지 않습니다. 원본 변경으로 한계돌파 보충 행이 누락되면 빌드가 오류로 중단됩니다.

## 스킬별 추정 피해 기여도

선택한 무기의 공격력·회심·속성과 힘의 부적(+6 기초 공격력)만 적용한 상태를 1.000으로 둡니다. 목표 스킬·검색 결과·레벨별 상세 모달에 추정 배율을 표시합니다.

- 전체 배율: 모든 계산 가능한 스킬을 적용한 피해 / 스킬 없는 기준 피해.
- 개별 스킬 배율: 현재 세팅 피해 / 해당 스킬만 제거한 피해. 서로 곱해 전체 배율을 구할 수 없습니다.
- 조건부 스킬은 발동/미발동 상태의 피해를 각각 계산해 평균합니다. 도전자 공격력·회심은 함께 켜고, 회심 상한을 상태별 적용합니다. 체력 최대는 붉은 체력·저체력과 배타적이고, 붉은 체력과 저체력은 함께 생길 수 있습니다.
- 건랜스 모든 타입에서 풀버스트, 용항 풀버스트, 참격·용항포, 모아포격·용격포를 혼합합니다. 사용 빈도는 공격 묶음의 상대 횟수이며 시간 또는 피해 지분이 아닙니다. 타입별 초기값은 측정 통계가 아닌 편집 가능한 가정입니다.
- 참격·용항 틱의 회심/속성, 비회심 폭발, 포격 고유 화염을 분리합니다. 속성 강화가 포격 고유 화염을 증가시키지 않습니다.
- 집중은 모으기에 쓰는 시간만 줄이는 근사입니다. 포탄 장전은 발사 수와 추가 모아포격 충전 시간을 반영하되, 장전 동작 및 용격포 게이지 수지는 미산정입니다.
- 정확한 사냥 DPS 또는 최적 세팅 보장이 아닙니다. 상태이상·일부 시리즈 효과는 미산정으로 표시하며 계산 가능한 효과 합계와 구분합니다. 피리의 선율·향주파와 속성 보우건은 현재 전체 피해 비교 미지원입니다.

계산 가정에서 육질·예리도·발동률·건랜스 사용 빈도를 조절할 수 있습니다. 가정은 로컬 설정/JSON 백업에 보존합니다. 검색 결과의 기존 정렬 기준은 유지합니다.

## 요구하지 않은 포스샷 복합 장식주 선택 수정

- 원인: 장식주 후보를 목표 충족량과 실제 소비 슬롯 크기로만 정렬하여, 모든 무기 슬롯이 Lv3이면 가드 성능1 단일주와 가드 성능1/포스샷3 복합주가 동점이 되고 DB 앞쪽 복합주를 선택했습니다.
- 같은 조건에서 장식주 요구 레벨, 요구하지 않은 스킬 레벨 합, 레어도, ID 순으로 동점을 해소합니다. 후보를 제거하지 않아 보유량 제약과 복합 스킬 필요 조건은 유지됩니다.
- 회귀22개·무작위300건 전수 비교6,506개 일치·실제 DB 참조 검사 통과. 새4회귀는 단일주 우선, 두목표 복합주 유지, 복합주만 보유, 단일주 수량 부족 시 혼용을 검증합니다.
- 실제 DB 재현: 가드 성능1/무기용3슬롯1개에서 수정 전 적탄-철벽주【3】 → 수정 후 철벽주【1】. 포스샷3도 요구하거나 복합주만1개 보유한 경우 적탄-철벽주【3】 유지, 모든 결과의 슬롯·목표·보유량 재검증 통과.

## 무기·속성에 유효한 복합 장식주 우선 선택

앞 절의 낮은 장식주 레벨 우선보다 먼저 무기별 추가 효과를 평가하도록 변경했습니다. 낮은 레벨을 고르는 규칙은 유효 추가 효과도 동점일 때 적용합니다.

- 전체 npm test 통과: 검색기 회귀35개, 무작위300건/만족조합6,506개 일치, 실DB 참조 및 기존개인장비/프리셋/이름인식 검증 유지.
